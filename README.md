# Солнечный календарь

Веб-приложение, которое находит дни текущего календарного года, когда в выбранном городе
**время восхода**, **время заката** или **продолжительность светового дня** совпадают
(или максимально близки) с соответствующими значениями сегодняшнего дня.

Все расчёты выполняются реальными астрономическими алгоритмами — без таблиц и эвристик.

## Возможности

- Поиск любого города с автодополнением (русские и другие названия).
- Точное время восхода и заката сегодня и длительность дня («9 ч 40 мин 42 с»).
- Три карточки результатов: «Закат в то же время», «Восход в то же время»,
  «Такая же продолжительность дня».
- Для каждой найденной даты: дата, день недели, значение, разница в секундах,
  количество дней относительно сегодня.
- Два режима: **точное совпадение** (±1 с) и **практическое** (настраиваемый допуск, по умолчанию ±60 с).
- Несколько совпадений в пределах допуска показываются все, в хронологическом порядке.
- Корректная работа с високосными годами, часовыми поясами IANA и переходами на летнее/зимнее время.
- Обработка полярного дня и полярной ночи.
- Кэширование расчётов по городу и году (память + `localStorage`).
- Адаптивный и доступный интерфейс на русском языке.

## Стек

- **Frontend:** React 18 + TypeScript, сборка Vite.
- **Стили:** обычный CSS (без внешних UI-библиотек).
- **Астрономия:** [`suncalc`](https://github.com/mourner/suncalc) — реализация алгоритма NOAA
  с определением восхода/заката по высоте центра Солнца **−0,833°** (верхний край диска у горизонта).
- **Часовые пояса:** [`luxon`](https://moment.github.io/luxon/) — база IANA, переходы на летнее время.
- **Геокодер:** [Open-Meteo Geocoding](https://open-meteo.com/en/docs/geocoding-api) (на базе GeoNames) —
  бесплатно, **без API-ключа**, поддерживает русский язык и возвращает IANA-часовой пояс города.

## Запуск локально

Требуется Node.js 18+ (проверено на Node 24).

```bash
npm install
npm run dev        # http://localhost:5173
```

Продакшен-сборка:

```bash
npm run build      # проверка типов + сборка в dist/
npm run preview    # предпросмотр сборки
```

Тесты:

```bash
npm test           # vitest run
npm run test:watch
```

Демонстрация расчётов без браузера (выводит реальные числа в консоль):

```bash
npx vite-node scripts/smoke.ts
```

## Зависимости и API-ключи

**API-ключи не требуются.** Единственный внешний сервис — геокодер Open-Meteo, он бесплатный
и открытый. Астрономические расчёты выполняются целиком на клиенте, поэтому приложение работает
даже без доступа к сети после выбора города (поиск новых городов требует интернета).

Если геокодер недоступен, можно воспользоваться блоком «Популярные города» — их координаты
и часовые пояса встроены в приложение.

## Алгоритм поиска дат

1. Определяется текущая местная дата и календарный год в часовом поясе города (`luxon`, IANA).
2. Для сегодняшней даты вычисляются восход, закат и длительность дня
   (длительность = момент заката − момент восхода, без округления промежуточных значений).
3. Те же показатели вычисляются для **всех** остальных календарных дат года
   (365/366 дней, високосные годы учитываются).
4. Для каждого из трёх показателей ищутся даты, значение которых отличается от сегодняшнего
   не более чем на допуск (по умолчанию 60 с). Сравнение ведётся в секундах с дробной частью,
   а не по «ЧЧ:ММ».
5. Сегодняшняя дата исключается из результатов.
6. Если дат в пределах допуска несколько — показываются все, в хронологическом порядке,
   с пометкой «до сегодня» / «после сегодня».
7. Если совпадений в допуске нет — показывается **ближайшая** дата, и явно сообщается,
   что это ближайшее, а не точное совпадение (показывается фактическая разница).
8. Корректно обрабатывается отсутствие дат с одной из сторон в начале/конце года.

### Определение восхода и заката

Единое определение: **верхний край солнечного диска**, высота центра Солнца ≈ **−0,833°**
относительно идеального горизонта (рефракция + угловой радиус Солнца). Это стандарт, который
использует `suncalc` и NOAA.

### Полярный день и ночь

Если Солнце в данную дату не пересекает горизонт, `suncalc` возвращает недопустимый момент.
Приложение классифицирует такую дату по высоте Солнца в местный полдень:

- высота ≥ −0,833° → **полярный день** (длительность дня = 24 ч, восход/закат не происходят);
- высота < −0,833° → **полярная ночь** (длительность дня = 0, восход/закат не происходят).

## Тесты

Покрывают требования к качеству:

- обычный город в средних широтах (Москва);
- город в Южном полушарии (Сидней, сезонность зеркальна);
- переход на летнее и зимнее время (Берлин);
- високосный год (2028: 366 дней, 29 февраля);
- начало и конец года;
- отсутствие точного совпадения (возврат ближайшей даты);
- несколько совпадений в пределах допуска;
- полярный день и полярная ночь (Тромсё);
- сверка с эталонными значениями sunrise-sunset.org.

## Примечания

- Город определяется только по явному выбору/вводу пользователя; IP-адрес не используется.
- Сетевые ошибки геокодера обрабатываются с тайм-аутом (10 с) и понятными сообщениями.
