# Солнечный календарь

Небольшое React-приложение, которое для выбранного города находит в текущем местном календарном году дни с похожими временем восхода, временем заката и продолжительностью светового дня.

## Запуск

```sh
cd solar-calendar
npm install
npm run dev
```

Parcel откроет приложение на `http://localhost:1235`. Для production-сборки выполните `npm run build`, для автоматических проверок — `npm test`.

## Использование

Введите не менее двух символов названия города и выберите вариант из списка. Приложение определит координаты и IANA-часовой пояс по геокодеру Open-Meteo, покажет местные значения на сегодня и сравнит их со всеми датами текущего местного года.

Допуск по умолчанию — 60 секунд. Установите `0`, чтобы искать точные совпадения. Если в допуск не попала ни одна дата, карточки покажут ближайший день до и после сегодняшнего, когда такие даты существуют; фактическая разница всегда указана.

## Расчёт

- [SunCalc 2.x](https://github.com/mourner/suncalc#readme) вычисляет восход и закат для координат с высотой центра Солнца около −0,833°.
- Для каждой даты отдельно преобразуется местный полдень в UTC и определяется смещение IANA-зоны на этот день. Смещение передаётся в `getTimes`, чтобы SunCalc вычислял именно гражданский календарный день выбранного часового пояса; это учитывает переходы DST и даты, где UTC-смещение отличается.
- Время восхода и заката сравнивается как местное время суток с дробной секундой. Длина дня вычисляется как разница реальных UTC-моментов заката и восхода; промежуточные значения не округляются.
- Полярные дни и ночи SunCalc отмечает отдельно. Для них приложение сообщает, что восхода или заката нет, и не строит совпадения по отсутствующему событию.
- Результаты года и ответы геопоиска кэшируются в памяти. Поиск не использует IP-адрес.

## Зависимости и сеть

React и TypeScript используются для интерфейса и типов, Parcel — для сборки, SunCalc — для астрономических расчётов. Города и их часовые пояса загружаются с `geocoding-api.open-meteo.com`. Для публичного геокодера ключ не нужен; для поиска нужен интернет. У поиска есть тайм-аут, обработка сетевых ошибок и ответа с ограничением запросов. [Open-Meteo указывает отдельный API-ключ для коммерческого доступа к зарезервированным ресурсам](https://open-meteo.com/en/docs/geocoding-api).
